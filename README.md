# The Temporal Displacement Protocol

A full-stack, text-based, time-travel choose-your-own-adventure game with persistent
MongoDB storage, dynamic LLM narrative generation via OpenRouter, timeline continuity
preservation, and browser-native audio narration.

You are a temporal researcher from the Year 3200, crash-landed somewhere between
1490 and 1890 A.D. You have 10 jumps to get home. Every choice drains (or siphons)
your displacement device's charge and ripples through history.

## Game Model

The game progresses over 10 discrete scenes. The state at step `i` is the tuple
`S_i = <Y_i, C_i, B_i, H_i>`:

| Symbol | Meaning | Range |
| --- | --- | --- |
| `Y_i` | Current year in the timeline | 1490–3200 (start `Y_1` ∈ [1490, 1890]) |
| `C_i` | Temporal device charge | 0–100 (`C_1 = 100`) |
| `B_i` | Cumulative Butterfly Effect (timeline disruption) | 0–100 (`B_1 = 0`) |
| `H_i` | Immutable registry of all generated scenes | — |

Charge follows `C_{i+1} = C_i + ΔC(a)` where `ΔC` depends on the risk level of the
chosen action (`Low` −12, `Medium` −10, `High` −5, `Temporal` +25 at the cost of
heavy timeline disruption). Disruption accumulates stochastically per risk level.

**Success condition:** reach Scene 10 with charge remaining — the device makes its
final jump to 3200. Run dry and you are stranded; your debriefing is generated by
the Year 3200 chronological supercomputer either way.

### The Continuity Rule (Immutability of History)

- **Write path:** the OpenRouter LLM is called *only* when generating the next scene
  from a player's choice. The narrative payload is written permanently to MongoDB.
- **Read path:** the Timeline Log, page reloads, and the finale's alteration list are
  served verbatim from the database. Existing scenes are never regenerated.

## Stack

- **Backend:** Node.js, Express, Mongoose (MongoDB), Axios → OpenRouter Chat Completions
- **Frontend:** React 18 + Vite, Web Speech API narration, retro-terminal CSS theme
- **LLM:** any OpenRouter model (default `google/gemini-2.0-flash-001`), strict JSON output

## Setup

### Prerequisites

- Node.js 18+
- MongoDB running locally (or a connection string for a cluster)
- An [OpenRouter](https://openrouter.ai) API key

### 1. Backend

```bash
cd backend
npm install
```

Edit `backend/.env`:

```env
PORT=3001
MONGODB_URI=mongodb://127.0.0.1:27017/timetravelgame
OPENROUTER_API_KEY=your_openrouter_api_key_here
AI_MODEL=google/gemini-2.0-flash-001
```

Start the API:

```bash
npm run dev   # nodemon, or: npm start
```

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

The app opens at `http://localhost:3000` and proxies `/api` to the backend on port 3001.

## API

| Method | Route | Description |
| --- | --- | --- |
| `POST` | `/api/game/start` | Create a new game; generates Scene 1 via the LLM |
| `GET` | `/api/game/:id` | Fetch stored game state verbatim (never calls the LLM) |
| `POST` | `/api/game/choice` | Submit `{ gameId, choiceId }`; advances the timeline |
